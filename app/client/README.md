## GoldPulse AI

GoldPulse AI is an XAU/USD paper-trading dashboard for learning disciplined,
transparent decision-making. It presents market context, technical and sentiment
signals, duration-specific trade plans, and risk guardrails without connecting to
a broker or placing real trades.

### Run locally

From `app/client`:

```sh
npm install
npm run dev
```

### Quality checks

```sh
npm run build
npm run test:e2e
```
